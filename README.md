# Master-Thesis
Master Thesis of Niklas Kotschi with the title: "TARGET ASIC Characterization and Optimization for a Fiber- Based Phase Camera"
The Einstein Telescope (ET) is a planned next-generation gravitational wave observatory designed to detect spacetime distortions with unprecedented sensitivity. Accurate control of the alignment of the interferometer optics requires fast, spatially resolved phase sensing of the laser beam, which can be provided by a fiber-array based phase camera.

A cost efficient solution to digitize these multi-channel analog inputs is the TeV Array Readout Electronics with gigasample per second (GSa/s) sample rate and Event Trigger (TARGET) family of application-specific integrated circuits (ASICs).
This thesis characterizes and optimizes the TARGET ASICs for application in the fiber-array based phase camera.
Clock jitter from different sources are quantified, calibration, timing and synchronization methods are discussed.
In addition, the influence of lower sampling rate on the phase resolution is analyzed.
The results demonstrate improvements in data acquisition stability by decreasing the clock jitter and improving the phase resolution through calibration methods and sampling rate reduction and prove that TARGET ASICs are a suitable solution for a fiber-array based phase camera for next-generation gravitational wave detectors.
